# ESP32 红外一键宏遥控器 (esp32-autocontrol)

一个独立、轻量的 ESP32 红外遥控器:手机连上 ESP32 开的热点,浏览器打开网页即可
点键发红外;把「开机 → 选台 → 确认」一整套操作录成**宏**,一键回放。配对档位与
宏数据存在 NVS,断电不丢。

## 功能特性

- **SoftAP 直连**:上电即开热点 `esp32-ir`(默认无密码),手机浏览器访问
  `http://192.168.4.1` 即可使用,无需路由器/服务器。
- **内置信号库 + 三步配对向导**:内置 4 个信号档 + NEC1/NECx 双协议(Hisense-C 为
  NEC-extended 0xBF00,LG/Vizio 0x20 发 NEC1),向导支持动态扩充码表。全屏向导自动
  逐档电源测试锁档、再逐个校准功能键;没反应的键标为未定义,不伪造码。
- **虚拟遥控器**:POWER / 数字 / 方向 / 确认 / 音量 / 频道 / 静音 / 菜单等 23 键。
- **宏录制与回放**:录制按键序列与每步等待时间,命名存储(≤23 字),一键回放;
  回放中实时显示当前步,可随时「停止回放」中断。
- **一键宏物理按键**:把任意宏标为「按键宏」后,短按 GPIO5 物理键(接地)即回放
  该宏——不掏手机、不开页面;绑定存 NVS 断电不丢。
- **上电自动回放**:可配置「上电自动回放按键宏」,电源上电后自动回放当前绑定的
  按键宏一次(需已配对;未配对/未绑定则跳过并记日志)。
- **开机宏保护**:宏首键是 POWER 时,回放前会弹确认框。

## 硬件接线

| 红外发射模块(三线) | ESP32-WROOM-32 |
|---|---|
| VCC | 3.3V |
| GND | GND |
| DAT | **GPIO4**(默认,可在 menuconfig 改) |

| 一键宏按键(两线) | ESP32-WROOM-32 |
|---|---|
| 按键一端 | **GPIO5**(默认,可在 menuconfig 改) |
| 按键另一端 | GND |

> 一键宏按键:任意轻触/微动开关,一端接 GPIO5、另一端接 GND,不接上拉电阻——
> 固件使能内部上拉,**按下=低电平**,60ms 防抖后播放网页上绑定的「按键宏」。
> 上电时按住不会误触发(启动即按下需先松开再按)。

> 发射模块为 DAT/VCC/GND 三线 IR LED 发射板(非 HX1838 接收头)。经典 ESP32 的
> GPIO 输出电流有限(约 40mA/最大),大多数模块内置限流电阻可直接驱动;个别需
> 三极管驱动的模块若距离不足,可加一级驱动电路,代码不受影响。

## 编译

本机使用 ESP-IDF **6.0**(`/home/hrong/workspace/code/esp-idf-6.0`):

```bash
cd /home/hrong/workspace/code/esp32-autocontrol
source /home/hrong/workspace/code/esp-idf-6.0/export.sh
idf.py set-target esp32
idf.py build
```

产物:`build/esp32_ir_remote.bin`。工程启用 `MINIMAL_BUILD`,依赖全部为 IDF 内置
组件(esp_http_server / nvs_flash / RMT / WiFi),无第三方组件。

常用配置(`idf.py menuconfig` → "IR Remote Config"):

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `IR_TX_GPIO` | 4 | 红外发射 DAT 引脚 |
| `IR_CARRIER_HZ` | 38000 | NEC 载波频率(38 kHz) |
| `ONE_KEY_BTN_GPIO` | 5 | 一键宏按键引脚(接地触发,内部上拉) |
| `AP_SSID` | `esp32-ir` | SoftAP 热点名 |
| `AP_PASSWORD` | 空 | 留空 = 开放热点 |

## 烧录

```bash
idf.py -p /dev/ttyUSB0 flash monitor
```

烧录成功串口应出现 `esp32-ir-remote boot OK` 与 SoftAP 启动日志。

## 使用流程

1. **连热点**:给 ESP32 上电,手机连接 Wi-Fi `esp32-ir`(无密码)。若之前连过同名
   热点,先「忽略此网络」再连。
2. **打开网页**:手机浏览器访问 `http://192.168.4.1`。
3. **配对**:未配对页点「开始配对」,按向导三步走(接线勾稽 → 电源测试锁档 →
   逐个功能键校准),详见下文「配对向导」。换电视/信号不中,在遥控器视图点「重新配对」重走一遍。
4. **遥控**:在遥控器视图点任意键,即按当前配对档发出对应红外码。
5. **录宏**:在宏区点「开始录制」→ 在遥控器按键网格按需点键(会实时发红外) →
   「停止并保存」,输入名字。录制中可「取消」放弃。
6. **回放**:在宏列表点「播放」;若宏首键是 POWER,会先弹确认(电视是否已关闭)。
   回放中可点「停止回放」中断,或等待播完。
7. **删除宏**:点「删除」并确认。
8. **设一键宏(可选)**:在宏列表点某宏右侧的「按键宏」(变绿为「按键宏 ✓」),
   此后短按 GPIO5 物理键即可随时回放该宏;再点一次取消。一次只能有一个「按键宏」,
   新绑定自动替换旧绑定;删除已绑定的宏会自动清掉该绑定。
9. **上电自动回放(可选)**:绑定「按键宏」后,勾选宏区顶部的「上电自动回放按键宏」。
   之后每次电源上电,设备自动回放当前绑定的按键宏一次(需已配对);取消勾选后恢复
   手动。解除按键宏绑定会自动取消该勾选。

## 配对向导

首次使用先配对。向导分三步:**接线勾稽 → 电源测试锁档 → 逐个功能键校准**。设备
自动发码,你只需在手机浏览器回答「有反应 / 没反应」。

### 接线勾稽

配对前先核对接线(见上文「硬件接线」),并确认:

- 红外发射头对准电视、中间无遮挡;模块供电正常(DAT→GPIO4、VCC→3.3V、GND→GND)。
- 电视处于可收红外状态(部分电视在关机/节能模式下不响应红外,会误判为「没反应」)。
- 手机已连 `esp32-ir` 且浏览器可打开 `http://192.168.4.1`;连过同名热点的话先
  「忽略此网络」再连。

### 三步流

1. **开始配对**:手机连 `esp32-ir` → 浏览器打开 `http://192.168.4.1` → 未配对页点
   「开始配对」。
2. **电源测试**:设备自动发「电源」并问"电视有反应吗?"——点「有反应」锁定当前
   信号组,进入功能键校准;点「没反应」自动切下一个信号组再试;4 组都不中则停在
   「没有匹配的信号组」,点「返回」可重新开始。配对时页面顶部显示当前信号组
   「信号组 N/M · 组名」(如「信号组 3/4 · Hisense NECx 0xBF00」),组名随信号组
   切换实时更新。
3. **功能键校准**:设备逐个自动发 12 个功能键(音量± / 频道± / 静音 / 菜单 /
   退出 / 确定 / 上 / 下 / 左 / 右),逐个回答「有反应 / 没反应」;答完即配对完成,
   校准档存入 NVS,断电不丢。

向导中可随时「取消」(保留原配对)或「没看到信号?重新发送」(页面刷新后恢复当前步)。
重开机后校准档仍在;在遥控器视图点「重新配对」会重走向导并覆盖旧档。

### 未定义键

「没反应」(或该信号组本就无可靠码)的键会标为**未定义**,在遥控器视图中**灰色
显示**;点未定义键不发任何红外码(固件原则:不伪造红外码,未知键一律不发)。
已定义键为白色可点。

> **已知开放问题**:内置信号库来自公开码库(Hisense-USA 官方离散码表、LG/Vizio
> 通用 NEC 等),与具体电视型号**可能不匹配**(待补真实码)。若向导全部「没反应」,
> 先用 `/api/key/raw` 从 LIRC / IRremoteESP8266 / SmartIR 等公开码库查真实 NEC
> 地址/命令试帧,待验证后把真实码补进信号库。

## REST API 一览

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/api/status` | 当前配对档、宏列表、回放/录制状态 |
| GET | `/api/profiles` | 信号库档列表(含每档是否全键可用) |
| POST | `/api/pair` | 配对标定档 `{"profile_id":N}` |
| POST | `/api/key` | 立即发一个键 `{"key":"POWER"}`(可带 `profile_id` 做电源测试) |
| POST | `/api/key/raw` | 发原始 NEC 帧 `{"address":0x04,"command":0x1F}`(开发/码源验证) |
| POST | `/api/macro/start` / `step` / `save` / `play` / `stop` / `delete` | 宏录制/回放/删除 |

`POST /api/macro/play` 另接受可选布尔字段 `one_key`,同时复用为「一键宏」绑定接口:
`{"id":N,"one_key":true}` 把宏 N 绑为按键宏(并照常回放,缺 N 返回 404);
`{"id":N,"one_key":false}` 仅当 N 为当前绑定时解除。绑定/解除与回放状态无关——
回放中也能绑定,之后按键即可播。

`POST /api/macro/play` 还接受可选布尔字段 `selfstart`,复用为「上电自动回放」开关
(仍不新增路由):`{"id":N,"selfstart":true}` 开启(宏 N 须为当前按键宏),
`{"id":N,"selfstart":false}` 关闭。`GET /api/status` 新增根字段 `"selfstart":0/1`
(0=关、1=开,默认 0),布尔值字段只做 additive 扩展,老前端兼容。

错误统一返回 `{"error":"..."}`(英文串,网页端会显示为中文提示)。

## 常见问题

- **电视没反应**
  - 确认发射头对准电视、接线正确(DAT→GPIO4)、模块供电正常。
  - 不同品牌/型号的红外码组不同:在配对向导里逐档做电源测试。
  - 若内置 4 档都不中,可从公开码库(LIRC、IRremoteESP8266、SmartIR 等)查你的
    电视真实 NEC 地址/命令,用 `/api/key/raw` 直接试帧(开发者调试入口)。
  - 注意「电源」键有些电视是离散开关码,重复按不一定每下都有反应。
- **如何中断回放**:网页宏区点「停止回放」。回放中按键网格会禁用(急停不应通过
  点按键触发),需用「停止回放」按钮。
- **按物理键没反应**:确认按键接线(GPIO5↔GND,见上文「硬件接线」)、网页上已把
  某宏设为「按键宏 ✓」;回放/录制中按键会被忽略(防竞争),待到空闲再按。启动日志
  应出现 `one-key button init: GPIO5 active-low`;`ONE_KEY_BTN_GPIO` 与
  `IR_TX_GPIO` 相同会导致按键被禁用(日志提示),需改为不同引脚。
- **上电不自动回放**:勾选「上电自动回放按键宏」要求已配对 + 已绑定「按键宏」。
  上电回放前电视需已通电;若宏首键是 POWER,仍会先弹确认(同手动回放)。启动日志
  可见 `selfstart: ...` 说明为何跳过(未开启/未绑定/未配对)。
- **分区与存储**:自定义分区表 `partitions/4m.csv` —— `nvs`(0x9000 起,32KB)、
  `phy_init`、`factory` 应用分区(0x20000 起,约 1.9MB)。配对档、宏索引与步骤
  都存在 NVS,**断电不丢**。容量:最多 16 条宏,每条 ≤ 100 步。
- **编译报错/环境**:确认先 `source export.sh` 再 `idf.py`;工程目标为 `esp32`
  (4MB Flash),不要切到其他目标。
- **连不上热点**:确认串口/供电正常;手机连接开放热点时若提示无互联网属正常,
  浏览器直接访问 `192.168.4.1`。

## 本地自测(无硬件)

固件把可测的纯逻辑(编码器 / HTTP 分发 / 宏核心)做成 host 自测,用普通 `cc`
即可跑:

```bash
cc -Wall -DIR_SELFTEST   -I main -o /tmp/ir    main/ir/test_ir_encoder.c   && /tmp/ir
cc -Wall -DWEB_LOGIC_SELFTEST -I main -o /tmp/wl main/app/test_web_logic.c && /tmp/wl
cc -Wall -I main -o /tmp/macro main/app/test_macro_engine.c                && /tmp/macro
cc -Wall -I main -o /tmp/bt    main/app/test_button_core.c                && /tmp/bt
```

通过时分别输出 `IR_SELFTEST_PASS` / `WEB_LOGIC_SELFTEST_PASS` /
`MACRO_SELFTEST_PASS` / `BTN_SELFTEST_PASS` 且退出码 0。
